# E-Commerce Data Analysis using NumPy and Pandas

## Overview
This project analyzes E-commerce order data using Python, NumPy, and Pandas.

## Features
- Sales Analysis
- Revenue Calculation
- Discount Analysis
- Customer Order Insights
- Statistical Summaries

## Technologies Used
- Python
- NumPy
- Pandas
- Google Colab

## Objective
To perform data analysis and extract meaningful business insights from an E-commerce dataset.
